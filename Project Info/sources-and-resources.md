1. **Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (Lewis et al., 2020)**
   - Theoretical foundation for injecting external context documents into LLM attention windows to eliminate factual hallucination.
2. **Cognitive Load Theory in Software Engineering (Sweller / Storey et al.)**
   - Rationale for the Stratigraphy UI model: partitioning large-scale codebases into distinct conceptual planes to reduce cognitive overload during onboarding.
